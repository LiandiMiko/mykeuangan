Status: Partial (Seluruh implementasi, modularisasi penuh 25 modul UI, perbaikan P0–P2, hardening DOM `renderHtml`/`renderSelectOptions`, test suite, serta sinkronisasi rilis selesai dan terverifikasi via `aislop:aislop_scan` + `konoha:token_efficient_grep`; eksekusi runtime `npm test`, `npm run build:prod`, serta deploy Edge Functions Supabase dijalankan pengguna via PowerShell/CLI lokal)

## Cakupan & Temuan yang Ditangani (P0–P3)

1. **[P0 - Production Static CSS Bug] Kelas Dinamis Tailwind di Budgeting (`web/ui-budget.js`)**: `getBudgetStatusInfo()` sebelumnya mengembalikan nama warna dasar untuk dirakit lewat interpolasi `bg-${...}` / `text-${...}` sehingga dipangkas oleh compiler static Tailwind CSS saat build produksi. Kini dikembalikan sebagai class string statis utuh (`barBgClass`, `badgeClass`, `progressClass`, `iconColorClass`, `pctTextClass`).
2. **[P0 - XSS Defense] HTML-Entity Decoding & Penyalahgunaan `escapeAttrJS` (`web/ui-state.js`, `src/features-v35.html`, `web/ui-wallets.js`, `web/ui-feat-analytics.js`, `web/ui-feat-modals.js`)**: `escapeAttrJS()` sebelumnya hanya men-escape karakter mentah tanpa escape `&` terlebih dahulu sehingga entity seperti `&#39;` bisa didekode browser menjadi kutip tunggal di dalam `onclick="..."`. Sekarang urutan escape mendahulukan `\\`, `'`, `\r`, `\n`, `\u2028`, `\u2029` sebelum `&`, `<`, `>`, `"`, dan seluruh atribut HTML biasa (`aria-label`, `title`, `value`, `class`, `data-*`) memakai `escapeHtmlJS()`.
3. **[P0 - DOM Injection Hardening] Penghapusan 39 Temuan `security/innerhtml` (`web/ui-state.js`, `web/supabase-auth.js`, `web/ui-*.js`, `web/ui-feat-*.js`)**: Rendering dinamis HTML dipusatkan ke helper `renderHtml(el, html)` berbasis `DOMParser().parseFromString()` yang menghapus elemen `<script>` (dengan wrapper kontekstual `<table><tbody>...</tbody></table>` untuk section tabel), dan pengisian `<select>`/`<datalist>` diseragamkan lewat helper DOM murni `renderSelectOptions()`.
4. **[P1 - Startup Performance] Auto-Refresh Harga Pasar Non-Blocking (`web/ui-shell.js`)**: Sinkronisasi harga Live CoinGecko/emas/kurs pada startup dipindahkan ke background async `refreshMarketPricesInBackground()` dengan cooldown `sessionStorage` 10 menit dan sinkronisasi snapshot lokal agar render UI pertama langsung tampil cepat.
5. **[P1 - PWA Offline] Celah Caching Google Fonts & Respons Miss SW (`web/sw.js`)**: Pengecualian SW yang sebelumnya mencakup semua host `googleapis.com` (ikut memblokir caching `fonts.googleapis.com`) dipersempit ke `url.hostname === 'generativelanguage.googleapis.com'`, ditambah precache `./icons/icon-192.png` dan fallback offline cache miss `503 Service Unavailable`.
6. **[P1 - Build & CSP Hardening] `build.mjs` & `package.json`**: Menambahkan `package.json` (`test`, `build:css`, `build`, `build:prod`), menyusun urutan inlining `UI_CORE_MODULES` + `UI_FEATURES_MODULES`, melempar error eksplisit jika regex Play CDN gagal saat `web/vendor/tailwind.min.css` tersedia, serta memangkas `'unsafe-eval'` dan `https://cdn.tailwindcss.com` dari CSP produksi di `dist/index.html`.
7. **[P1 - Telegram Bot Parity & Stability] `supabase/functions/telegram-bot/*.ts`**: Mengubah model default ke `gemini-2.5-flash` (`core.ts`), menambah loop fallback `GEMINI_FALLBACK_MODELS` + `.json().catch(() => ({}))` + `matchWalletFromText` pada `/insight` (`ai.ts`, `wallets.ts`), mendukung deteksi dompet pintar di handler tambah/free-text, menampilkan jumlah kategori akurat `rows.length` di `/budget copy`, membuka `/recurring add` untuk tanggal `1..31` (`planning.ts`), dan merapikan `keterangan` + cache `wallet_id` default pada job cron (`jobs.ts`).
8. **[P2 - Fonts, Shadows & i18n] (`src/styles.html`, `src/i18n.html`, `web/ui-feat-account.js`)**: Memindahkan Inter Google Fonts dari `@import` blocking CSS ke `<link>` `crossorigin="anonymous"`, menyamakan token `boxShadow.xs` di fallback inline Tailwind, serta menambahkan `updateDashboardTitle()` pada akhir `applyTranslations()` agar judul Dashboard mode Inggris (`EN`) tidak tertimpa string hardcoded.
9. **[P2 - Observability & Modularisasi Total Frontend] (`web/ui-*.js`, `web/ui-feat-*.js`)**: Memecah seluruh ~6.200 baris JavaScript inline dari `src/script.html` (`15 web/ui-*.js`) & `src/features-v21.html` (`10 web/ui-feat-*.js`) menjadi modul fokus <330 baris, memecah `buildPortfolioChartConfig()` (`web/ui-assets.js`) dan mengekstrak helper konfirmasi admin `confirmAndApplyAdminChange()` (`web/ui-admin.js`), menghapus duplikat dead code `openNotificationsModal`, dan mengganti penamaan generik di hook Split Bill (`web/ui-feat-hooks.js`).
